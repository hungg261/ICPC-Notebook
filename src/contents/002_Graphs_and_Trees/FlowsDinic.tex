% Dinic Algorithm

Max flow and min-cut algorithm running in $O(V^2 E)$ (worst case) and $O(E \sqrt{V})$ on unit networks.

\lstinputlisting{contents/002_Graphs_and_Trees/codes/FlowsDinic_1.h}

\begin{itemize}
    \item Call \lstinline|max_flow()| first to compute the maximum flow from \lstinline|source| to \lstinline|sink|.
    \item The array \lstinline|level| retains the reachability from \lstinline|source| in the residual graph. A node $v$ is on the source side of the cut if \lstinline|level[v] != -1|.
    \item Call \lstinline|min_cut()| after \lstinline|max_flow()| to get all edges belonging to the minimum cut partition.
\end{itemize}
