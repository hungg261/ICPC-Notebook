% Chinese Remainder Theorem (CRT)

Solves $x \equiv r_i \pmod{m_i}$ for non-coprime moduli. Returns \lstinline|{ans, lcm}|, or \lstinline|{-1, -1}| if impossible.

\lstinputlisting{contents/003_Math/codes/CRT_1.cpp}

Usage guide for $x \equiv r_i \pmod{m_i}$:
\begin{itemize}
    \item Pass equations as \lstinline|{r_i, m_i}| into \lstinline|vector<pair<long long, long long>> eq|.
    \item Call \lstinline|auto [ans, lcm] = crt(eq);|. If \lstinline|lcm == -1|, no solution exists.
    \item Safe guard: Ensure $0 \le r_i < m_i$ before calling to avoid incorrect \lstinline|r2 - r1| signs inside.
\end{itemize}
